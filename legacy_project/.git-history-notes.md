# Commit history notes

This project is synthetic. Rather than shipping a real `.git` history, this file
describes the history an engineer would see if they ran `git log` on it. Read it
the way you would read a real one: as evidence of how the code got this way.

Names are fictional.

---

## The short version

Three people have owned this project across two years. Each left a different set
of conventions behind, and nobody ever went back and reconciled them.

---

Set up the project during the SQL Server migration. Established the
`stg_` / `int_` / `dim_` / `fct_` layering and the CTE-only style. Wrote tests
for everything she built.

Left the company end of June 2023.

## 2023-07 to 2024-03 — Dan Pritchard, maintenance and BI requests

Came from a SQL Server background and wrote in that idiom: `v_` prefixes for
anything view-shaped, nested subqueries rather than CTEs. Did not add tests,
mostly because the requests came in as urgent BI fixes.

## What the history does not tell you

- Nobody has reconciled the three naming conventions.
- The README was last meaningfully updated at Priya's handover in June 2023.
  Everything after that is undocumented, and some of what it describes has since
  been removed.
- `sql/adhoc/` was never reviewed. It was added under deadline and left there.
- There is no test coverage on anything added after June 2023.
